# BPSR Android DPSMeter Relay v1.1.3

## Reliability and setup

- Keep the temporary phone-profile server available for repeat SFA downloads throughout the five-minute setup window. A download alone is not treated as confirmed import.
- Preserve explicit phone-import confirmation when the same profile is downloaded again; invalidate confirmation if the profile identity changes.
- Make Run Check reflect phone-import confirmation and distinguish the app's temporary setup listener from an unrelated port conflict.
- Match firewall readiness to supported Windows Private networks instead of treating a domain-authenticated network as ready when the rules are Private-only.
- Verify the pinned sing-box runtime before startup or repair, verify executable copies, and avoid redundant hash work while the application is idle.
- Clean up an owned relay process if its companion exits, preserve tracking if stopping fails, and distinguish a temporary listener probe failure from a stopped relay.

## Performance and validation

- Keep the WinForms interface responsive during guided Start, Stop and Restore; reduce idle polling and dispose asynchronous socket wait handles.
- Strengthen two-stage TCP smoke tests against proxy bypass and invalid SOCKS credentials. Add an authenticated two-stage localhost UDP ASSOCIATE/echo test and native phone-profile regression coverage.
- Repair native field-test packaging. The relay topology and pinned sing-box v1.13.19 remain unchanged.

## Updating

Close the manager, extract the ZIP and replace the application files in the existing relay folder. Retain your generated phone profiles and runtime state. If asked to reimport the phone profile, prefer a local JSON import into SFA; for a QR-imported remote profile, disable Auto Update after import because the private setup URL is temporary. Capture traffic from **StarSEA**, not BPSRMobileFront.

## Verification scope

Windows CI tests exercise the native build, profile-state regressions, UI bootstrap, local TCP/UDP relay smoke and package integrity. They are not a substitute for real Android/SFA gameplay tests: BPSR-only routing, StarSEA DPS capture, live combat traffic, Wi-Fi reconnection and sustained latency/resource behavior must be verified before publishing or describing this version as a stable field-tested release.
