# BPSR Android DPSMeter Relay v1.1.2

## Fixed

- Fixed **Allow Firewall** failing with “Value does not fall within the expected range” when reading the Windows network adapter ID.
- Recognize Windows' equivalent single-host IPv4 address formats when checking firewall rules.
- Show the failed setup stage and Windows error code instead of an unexplained error, and avoid a second generic popup.
- Make the existing Windows network/firewall check fail correctly when its process reports an error.

## Setup improvements

- Keep the window responsive while preparing the relay or waiting for Windows firewall approval, with visible progress and protection against repeated setup clicks.
- Treat a cancelled Administrator prompt as a cancelled action, so you can retry when ready.
- Replace confusing Yes/No phone-import choices with **Open Phone Setup**, **Already Imported**, and **Cancel**.
- Shorten clipped setup instructions and make the daily startup order easier to read.
- Keep controls reachable with scrolling when Windows display scaling makes the window larger than the available screen.

## Updating

Close the manager, extract the release ZIP, and replace the application files in your existing relay folder. Keep your existing generated profiles and runtime folders. Run **Allow Firewall** again, then continue with phone setup if prompted.

The relay remains restricted to the selected PC address, the Private network profile, local-subnet clients, and TCP/UDP port 10808. The sing-box version and relay data path are unchanged.
